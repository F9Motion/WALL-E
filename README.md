# Features
* Minimalistic design
* Persone from cartoon
* You like this
* Wireless
* You can control robot with controller
# How it works
When you push buttons in remote controller a special diode gives to **ESP32** signal and ESP32 gives command to motors "move!". ESP32 contacted with motors in PCB. To teach ESP32 what command give to motors I write **firmware**.
# How to assemble
1. Order PCB and parts for project(You can find parts in BOM)
2. Solder parts to PCB
3. Print all **CAD** files
4. Flash ESP32
5. Assemble it
# How to flash
1. Download arduino IDE
2. Add add-one for ESP32
3. Open my firmware
4. click to here to flash!
